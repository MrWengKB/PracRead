<h1>朗读练习</h1>
输入文本，练习朗读。支持显示汉语拼音。可录音。使用Azure为朗读评分。
可以设置班级、学生名单，并发布作业给特定班级。

## 页面

| 页面 | 给谁用 | 作用 |
| --- | --- | --- |
| `index.html` | 老师 | 输入篇章、自己试读；「设置」里连接成绩表、导入学生名单；「发布作业」生成学生链接 |
| `practice.html` | 学生 | 只能通过老师发的链接打开；选名字、朗读、自动评分，成绩写入 Google Sheet。没有输入文本的地方 |

作业链接有两种：

- **记成绩的链接** `practice.html?a=作业ID`：篇章、班级存在 Google Sheet 的「作业」分页里，链接短，学生从下拉菜单选名字，每次评分都记一行成绩。
- **不记成绩的链接** `practice.html#p=……`：篇章直接编码在链接里，不需要成绩表，学生可练习和看分数，但不记名。

## 设置成绩表（只需做一次，约 10 分钟）

1. 打开 [Google Sheets](https://sheets.google.com)，新建一个空白表格，取名如「朗读成绩」。
2. 点菜单 **扩展程序 → Apps Script**。
3. 把编辑器里原有的代码全部删掉，把本仓库 [`apps-script/Code.gs`](apps-script/Code.gs) 的全部内容粘贴进去。
4. 在代码开头找到 `const TEACHER_KEY = "改成你自己的密码";` 引号里的字改成你自己的密码（至少 4 个字符，不要告诉学生）。按 💾 保存。
5. 点右上角 **部署 → 新建部署**，点齿轮选 **网页应用**：
   - 执行身份：**我**
   - 谁可以访问：**任何人**
   - 点「部署」，第一次会要求授权：选你的 Google 账号 → 「高级」→「转至……（不安全）」→「允许」。（这是你自己写的脚本，Google 对所有未审核脚本都会这样提示。）
6. 复制出现的 **网页应用网址**（`https://script.google.com/macros/s/……/exec`）。
7. 打开朗读练习网站 → 右上角 **设置** → 贴上网址、填密码 → **保存并测试连接**，看到「✓ 连接成功」即可。
8. 在「学生名单」填班级名称，粘贴名字（每行一个，或从 Excel 直接复制，或选 CSV 文件）→ **导入 / 更新名单**。

之后发布作业：在首页输入篇章 → **发布作业** → 选班级 → **生成作业链接** → 复制发给学生。

> 以后如果修改了 Apps Script 代码，要点 **部署 → 管理部署 → ✏️ 编辑 → 版本：新版本 → 部署**，网址不变。

## 成绩表里的分页

- **作业**：每次发布一行。把「状态」改成 `关闭`，这份作业就不再收成绩（学生仍可练习）。
- **名单**：班级 + 姓名，也可以直接在这里改。
- **班级·作业名**（例如「P5A·第一课」）：每发布一份作业自动建一个分页，只列这个班的学生，显示每人的练习次数、最高分、平均分、最近练习时间。没练习的学生是空白，一眼看得出谁还没做。名单更新时，新同学会自动补进去。
- **成绩**：所有班级、所有作业的原始记录，学生每评分一次一行（时间、作业ID、作业标题、班级、姓名、各项分数、识别文字）。可用筛选按班级或作业查看。
- **汇总**：按班级 → 作业 → 学生排序的总表。

同一个班可以发布很多份作业，不同班也可以发布同一篇课文（各自一份作业、各自一个分页），成绩不会混在一起。

## 防刷措施

- 导入名单、发布作业要老师密码；
- 学生链接里的作业 ID 是随机的，猜不到；
- 只接受名单里的名字，分数限制在 0–100；
- 同一学生同一作业 15 秒内只能提交一次，每份作业每小时最多 400 条；
- 写入表格的文字会防止被当成公式。

限制：学生没有登录，拿到链接的人可以选别人的名字提交。如需要，可以以后给每个学生加一个简单的个人密码。
